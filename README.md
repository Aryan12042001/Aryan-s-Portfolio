### **S&P 500 Live Dashboard with ChatGPT Integration**  
**Project Overview**  
This dashboard is designed to visualize and analyze the S&P 500 index's performance across multiple timeframes. Built using Python’s Streamlit and Plotly libraries, it delivers real-time interaction and data analysis. The integration of ChatGPT enhances the user experience by providing contextual insights about selected data points, such as economic or news events impacting market performance (e.g., COVID-19 during 2019-20).  

**Key Features**  
- **Data Visualization**: Offers candlestick, line, bar, and table views for versatile analysis.  
- **Dynamic Filters**: Enables users to focus on specific timeframes like 1 month, 1 year, or the full dataset.  
- **Interactive Insights**: Allows users to click on a specific date to access detailed insights generated by ChatGPT.  

**Advanced Analysis**  
- Weekly percentage changes categorized into meaningful bins (e.g., "Significant Increase," "Extreme Decrease").  
- Custom color coding highlights increases and decreases for pattern recognition.  

**Macro-Economic Context**  
- Includes indicators like CPI, GDP, inflation rates, and S&P 500 earnings to add depth to market performance analysis.  

**Technical Details**  
- Preprocessed data for accuracy and performance, using Streamlit’s caching to optimize.  
- Implemented `plotly_events` to capture user interactions for deeper data exploration.  

**Impact and Future Applications**  
- A valuable tool for investors and analysts to make data-driven decisions.  
- Future scope includes expanding to other indices or stocks and incorporating predictive modeling.

### **Glycerin-to-Glycol Production Using Machine Learning**  
**Project Overview**  
This project optimizes the conversion of glycerin (a biodiesel by-product) into ethylene glycol (EG) and propylene glycol (PG). By leveraging machine learning, it predicts yields, identifies anomalies, and optimizes input variables to streamline production and enhance efficiency.  

**Key Features**  
- **Predictive Modeling**: Built models to forecast yields based on hydrogen flow, pressure, temperature, and other factors.  
- **Optimization**: Used a stacked model with a Genetic Algorithm to increase PG yield by over 7%.  
- **Anomaly Detection**: Implemented machine learning to flag operational issues and predict failures with accuracy.  

**Applications**  
- A potential app for workers to input real-time process parameters and get automated recommendations to optimize production.  
- Can be integrated directly with reactors for real-time automation and control.
